## §1-1 — Versioned Release Obligation (revised)

Every release of a standard governed by SpecWeave MUST be accompanied by a
canonical manifest that records the exact set of normative changes, the commit
SHA at which those changes were authored, and a cryptographic digest of each
source artifact. The manifest itself MUST be published at an immutable,
commit-pinned URL before the release proposal is submitted for review.
Implementations MUST satisfy all validation steps before the manifest is
accepted as evidence.

Normative level: MUST
Section: 1.1 Release Integrity
